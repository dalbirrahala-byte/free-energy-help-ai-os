## Renewal route

The live /business-energy-contract-renewal page currently:
- presents out-of-contract and deemed rates as though they are the same;
- contains the visible placeholder telephone number 01332 000000;
- uses broad recommended renewal timing statements that should be framed as FEH guidance rather than universal market rules.

Current Ofgem guidance lists rolling/evergreen, out-of-contract and deemed-rate contracts separately. The final copy should preserve those distinctions and point readers back to their specific contract terms.

## Duplicate renewal experience

The separate /business-energy-contract-renewal-review route currently displays 01332 605506, while the main renewal route displays 01332 000000. The two routes need canonical/intent review before any production edit so that search engines and users do not receive conflicting renewal experiences.

## Business-bill guide

The live /understanding-business-energy-bills page currently:
- describes MPRN as typically 8–10 digits, while Xoserve's current A-to-Z describes an MPRN as six to 10 digits;
- retains the historic statement that Profile Classes 05–08 indicate a half-hourly site;
- repeats a generic recommendation to start renewal three to six months before contract end.

The MPRN copy should use the current Xoserve six-to-10-digit wording. Historic profile-class shorthand should be reworked for the MHHS-era context rather than presented as a simple current rule.
