## Implementation

The private entry point is `runConfiguredPrivateTrial` in `frontend/scripts/privateAcknowledgementStaging.server.ts`. It is a server-only function for a private test host, with no public endpoint, scheduled job or provider transport. It accepts an explicitly supplied environment. It returns bounded mock evidence (status, attempt ID and call count). A mock success produces a synthetic UUID for the existing database finalizer. Keep mock records labelled in the test evidence and segregated from delivery metrics.

The driver discovers an enquiry using the reviewed selection function. Only the configured synthetic lead ID and the fixed test number can reach authorisation. Two separate restricted clients must verify their logged-in identities. The database still decides permission, suppression, emergency STOP and execution authority. The driver checks the fixed UTC interval before discovery and each subsequent operation and permits finalisation of an attempt already in progress. It has no retry loop. Keep the ordinary provider worker and Preview SMS flags disabled.

The Meta receiver now recognises an explicitly configured interval of up to 15 minutes on the staging Edge project. The new start setting is `FEH_META_FORM_TEST_STARTED_AT`. Both existing expiry settings must match exactly. All three times use the canonical UTC form with milliseconds. This path only admits the pinned Meta form/lead and synthetic test number. It checks the event time before retrieval and checks the interval again before queue and permission writes. The legacy window remains capped at 6 November. The new interval cannot open the legacy Google or Meta dashboard-test handler. The Google receiver retains its existing time-window behaviour.
